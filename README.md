# AI Secure Academy — Hydration Kit

Public distribution for the AI Secure Academy lab launcher. **Pre-release:** currently diagnostics only, no install or auto-update.

## Quick start

```powershell
git clone https://github.com/Marcope113/ai-secure-hydration-kit.git
cd ai-secure-hydration-kit
.\aisecure.ps1 -Action Check
```

After reviewed changes: `git pull --ff-only` then run Check again.

Private lab development stays in the Academy repository. Only tested artifacts will be distributed here.
